Caret language website
======================

This is a static website with no build step.

Publish the following files together at the document root for caret.dimage.se:

  index.html
  styles.css
  script.js

The site links to Google Fonts and therefore needs normal outbound browser access
to fonts.googleapis.com and fonts.gstatic.com. If those requests are blocked, the
site falls back to system sans-serif and monospace fonts.

For a quick local preview, open index.html in a browser or serve this directory
with any static web server.
