Experimental functional programming language

Caret is a small language for exploring big ideas.

Minimal syntax, pure functions, contracts, unified collections, and explicit metaprogramming. Caret is an approachable place to experiment with language design.

A work in progress.

01 / Philosophy

A compact language,
open for inspection.

Caret asks what a functional language might look like if advanced features stayed explicit and readable. Its small set of forms covers contracts, transformation, reflection, and safety without adding much ceremony.

01

Everything composes

Functions are values. Collections share a common vocabulary. Partial application is ordinary, not exceptional.

02

Intent is executable

Contracts and purity live with the code, turning assumptions into visible, checkable structure.

03

Power has boundaries

Reflection, compile-time work, and sandboxing are explicit—so advanced tools remain understandable.
