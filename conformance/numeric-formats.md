## Phase 4 numeric, conversion, and packed design

The [approved design and acceptance matrix](../spec/sections/06-02-packed-layouts.md#phase-4-packed-layouts-implemented)
complete the specification task #77 and define separate numeric (#82), conversion (#83), and packed
(#78) implementation gates. Numeric foundation, embedding, and explicit conversion rows are
implemented, including contiguous packed storage and its protocol.
The existing `DATA-COLL-006` and `TEMPLATE-OPT-001` requirements additionally require these selected
layouts and optimized/reference parity; homogeneous values alone are not packed membership.
The numeric, conversion, and packed rows below cite runtime tests and runnable examples. Packed
conversion retains selected membership in both contiguous and optimization-disabled reference mode.
